
# Meet&Mani 💅

### Discover beauty. Connect with talent. Book with confidence.

Meet&Mani is a full-stack beauty services marketplace designed to connect customers with independent nail technicians, helping beauty professionals showcase their skills, reach more customers and manage their businesses.

The project is currently in development, starting with nail technicians and with the potential to expand into other beauty services.

## The Problem

Many talented nail technicians, particularly independent professionals and those running small businesses, rely heavily on social media, word of mouth and messaging platforms to attract customers and manage appointments.

While these platforms are useful for promoting their work, they are not specifically designed for managing a beauty business.

This creates several challenges:

- **Limited visibility:** Customers may struggle to discover talented nail technicians outside their existing social networks.
- **Fragmented booking:** Customers often need to contact multiple professionals to compare services, prices and availability.
- **Business management:** Nail technicians may have to manage appointments, customer inquiries and portfolios across several different platforms.
- **Building trust:** Customers may find it difficult to compare professionals, view their work and make informed booking decisions.
- **Growth opportunities:** Independent nail technicians may lack access to affordable digital tools that help them establish a professional online presence.

These challenges inspired me to develop Meet&Mani.

## The Solution

Meet&Mani aims to bring beauty professionals and customers together on one accessible platform.

Instead of relying on several different applications to discover professionals, view their work and arrange appointments, customers will be able to complete their booking journey in one place.

For nail technicians, Meet&Mani will provide a dedicated digital space to showcase their work, list services, manage availability and organize appointments.

The long-term goal is to make professional beauty services easier to discover while giving independent beauty professionals practical tools to grow their businesses.

## Key Features

### For Customers
- Discover nail technicians by location.
- Explore professional profiles and portfolios.
- Compare available services and prices.
- View appointment availability.
- Book appointments online.
- Leave reviews after completed appointments.

### For Nail Technicians
- Create a professional business profile.
- Upload a portfolio of previous work.
- Add and manage services and prices.
- Set working hours and availability.
- Manage appointment requests.
- Access a dedicated business dashboard.

## Getting Started

### Prerequisites

- Node.js and npm
- Git
- VS Code or another code editor

### Installation

Clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/meet-and-mani.git
```

Navigate to the project:

```bash
cd meet-and-mani
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL displayed in your terminal.
